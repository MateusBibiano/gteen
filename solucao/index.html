    Dados da sessão

    Os indicadores são estimativas automáticas para apoiar a observação do professor. Não são diagnóstico. O resumo de cada sessão fica salvo no histórico do aluno neste navegador; os dados segundo a segundo ficam só no CSV.

    Como treinar o modelo do aluno

    1. Calibre primeiro com o aluno em posição normal. O treino usa o rosto neutro como referência.
    2. Para cada emoção, clique em Gravar. Há 3 s de preparo e 3 s de gravação. Peça a expressão de forma natural ou grave quando ela acontecer de verdade.
    3. Grave cada emoção pelo menos 2 vezes, de preferência em momentos e posições diferentes. Isso permite medir a acurácia com honestidade.
    4. Clique em Treinar e avaliar. A avaliação testa cada gravação com um modelo treinado só nas outras.
    5. Durante as aulas, use a conferência do professor: cada toque também vira dado de treino.

    Nenhuma imagem é guardada: só 28 medidas numéricas do rosto por amostra.
